RADIO SOURCE DIVINE — application PWA
========================================
Flux radio déjà configuré:
https://stream.zeno.fm/7u0fw8vmzneuv

Fichiers:
- index.html : interface
- style.css : design
- app.js : lecteur radio
- manifest.json : installation comme application
- sw.js : cache PWA
- icons/ : icônes

MISE EN LIGNE
1. Hébergez tous les fichiers sur un site HTTPS.
2. Ouvrez le site avec Chrome/Edge ou Safari.
3. Sur Android/Chrome: utilisez "Installer l'application".
4. Sur iPhone/iPad: Safari > Partager > Ajouter à l'écran d'accueil.

PERSONNALISATION
- Remplacez le logo RSD par votre vrai logo dans index.html si vous en avez un.
- Remplacez le lien WhatsApp dans index.html par votre numéro.
- Ajoutez votre site et vos réseaux sociaux dans la section contact.
